⬇️ Export

Downloads a .json file containing every car, loan, staff record, remark, and setting currently in the database. Save this file before doing a Docker pull / redeploy.

⬆️ Import

Select a backup .json file produced by the Export above, choose a mode, then click Import. The server applies the restore inside a single transaction — either all rows land or none do.

⚠️ Replace mode deletes every car, loan, staff record, and remark from the database before restoring the snapshot. This cannot be undone. Only use this on a fresh install where you want to restore an earlier state completely.
